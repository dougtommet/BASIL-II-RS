# Analysis2

Copy this entire folder to `R/Analysis2/` in the BASIL-II-RS project. Retain the project's `.here`, `TEMPLATES/letter.css`, and `TEMPLATES/letter_css_scripts.html`.

Run locally from the project in R:

```r
source(here::here("R", "Analysis2", "Analysis2_Driver.R"))
```

The driver renders `Analysis2_Control.qmd` to HTML in place, stages `RENDER/Analysis2_agreement.html`, and copies a dated self-contained report to `REPORTS/`. It uses no `--output-dir` flag. The control file owns the input paths, bootstrap settings, and section order. Its default BASIL derived-data folder matches Rich's relative local path used by Analysis1; change that parameter if the local folder differs.

Install the packages listed in `000-Libraries.R` and the Quarto CLI locally before running. No script installs packages, accesses a remote service, or uploads data. The report uses the supplied CSS and its required after-body script, with every report section inside a `.page` block.

Technical tables have separate `.page` blocks with nested `.small` blocks and 9-point type. They use sequential T-prefixed letter labels: Table TA, Table TB, through Table TZ, then Table TAA, Table TAB, and so on. "T" denotes "Technical output"; the convention is explained in the report introduction. Manuscript tables retain numeric manuscript labels. All tables have descriptive titles and NOTES defining every displayed column. Agreement, weighting-comparison, complete-reviewer, and package-validation tables are split by outcome and rating stage to fit portrait pages. Constant descriptors appear in titles; the weighting column is retained when a table compares weighting schemes. The corresponding markdown exports use the same technical labels and notes. The table helper stops if column definitions do not match the displayed columns.

`manuscript-tables.qmd` is included immediately before the execution record. It prepares a separately numbered publication table set: Table 1 (entropy-balanced overall severity and presence agreement), Supplemental Table 1 (observed participant characteristics by site), and Supplemental Table 2 (entropy-balanced dementia-stratified agreement). All agreement results in manuscript tables and revised narrative use entropy-balanced participant weights. Equal-participant-weight comparisons and complete-reviewer sensitivity results remain in the technical report only; the former Supplemental Table 3 is withdrawn. No automatic threshold determines manuscript inclusion of comparison results: authors review the technical differences and decide whether weighting changes the scientific interpretation. Tables use horizontal rules, grouped rows, readable labels, and estimates with confidence intervals in the same cell. All values are rebuilt from current Analysis2 objects; no legacy estimates are copied. Each table is exported as standalone styled HTML and markdown in `MD/`, named `Analysis2_manuscript-table-1`, `Analysis2_manuscript-table-s1`, or `Analysis2_manuscript-table-s2`.

Missing-dementia notes and the missing-dementia summary row are reported only when at least one participant lacks dementia status. All current participants have dementia status. The technical complete-reviewer sensitivity analysis concerns missing reviewer ratings; it retains the original entropy weights for its primary-weighting variant and equal participant weights for its comparison variant. It reports point estimates only.

Manuscript agreement row labels include `(95% CI)` wherever estimates are presented with confidence intervals. Count rows and participant-characteristic summaries retain their count or SD labels.

The workbook import and participant harmonization are adapted from Analysis1. They read the original workbook and parent BASIL derived files locally, then build isolated `Analysis2_` interim files in `R/RDATA/`. The workbook remains at the legacy `SourceData/` location; all source inputs are read only. `DATA/SOURCE/`, `DATA/DERIVED/`, and Analysis1 outputs are untouched.

Primary estimates use our participant-weighted extension of Conger's generalized kappa, with entropy-balanced participant weights, quadratic agreement weights for severity, and identity agreement weights for presence. The extension applies participant weights to observed agreement and reviewer-specific category proportions; irrCAC's `weights` argument is for agreement categories, not participants. Setting every participant weight to 1 is checked against `irrCAC::conger.kappa.raw` for each estimable outcome, stage, and group, with identical categories and agreement weights. The maximum allowed absolute difference is 0.00001 because irrCAC rounds its returned estimate to 5 decimal places. The technical report displays the check and signed entropy-versus-equal-weight differences for every agreement measure. Paired stage changes are calculated under both weighting schemes using the same resampled participants and their fixed weights. Bootstrap intervals condition on the reviewer panel and fixed participant weights and omit weight-estimation uncertainty. The balancing target includes the entire enrolled cohort.

Entropy balancing supplies cohort means multiplied by the reliability sample size as target totals, because `ebalance()` constrains weighted sums. Weights sum to the reliability sample size; solver convergence and achieved weighted means are checked before the agreement analysis.

The covariate-balance table identifies the full-cohort target, the reliability sample before weighting, and the achieved values after entropy weighting in its column headers, with current sample sizes. Row labels distinguish mean reference-standard severity (0-10) from site proportions (0-1). The descriptive headers and labels are retained in markdown exports; calculation objects retain their original variable names.

Reviewer category proportions divide weighted category totals by weighted available-rating totals. The availability indicator must be parenthesized before multiplication by participant weights: in R, `!is.na(x) * w` negates the product rather than weighting the indicator. Omitting the parentheses leaves an unweighted denominator and can produce invalid entropy-weighted bootstrap kappas. Targeted regression checks are run with `Rscript R/Analysis2/tests/test-agreement-and-tables.R`.

All-pairs objects are created only in `070-graphics.R` and are used only for descriptive plots. Descriptive agreement statistics are computed within participant using category counts. Tables and figures carry an Analysis2 prefix. Undefined bootstrap estimates are counted and interval suppression is explicit.

`manuscript-redlines.qmd` contains exact passages from the current manuscript PDF, with whitespace normalized. Old text is struck out, revised text follows, and new numerical results are inserted only when executed locally. Page references use PDF page numbering, counting the title page as page 1; the current PDF has 25 pages and no opening reviewer-response pages. Each original quotation cites the PDF and its page, without references to extraction files. No literature citations were added to the empty project bibliography. Internal resources and implementation documentation are cited inline.

Validation performed during preparation: R source and extracted QMD chunks were parsed without evaluation; QMD source structure, redline provenance, relative paths, and output names were checked. No participant data were read or analyzed and no HTML report was rendered during preparation.
